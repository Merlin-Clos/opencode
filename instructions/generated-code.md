# Generated Code Instructions

- Identify generated files from repository instructions, configuration, generation
  scripts, source comments, and Git metadata.
- Do not edit generated output by hand unless the repository explicitly defines it
  as an editable source.
- Change the source contract or generator, then regenerate output through the
  documented command.
- When generated contracts change, inspect their effect on consumers, adapters,
  mappings, and tests. Do not review or refactor generated style.
- Treat nested repositories and submodules as separate change boundaries. Do not
  modify one unless the task explicitly includes it.
